# Vimeo Embed Tool

Minimal tool to customize Vimeo embed appearance. Paste a Vimeo URL or video ID, toggle options, and copy the generated iframe code.

- **Live preview** — changes update the embed in real time
- **All toggles** — badge, autopause, autoplay, loop, muted, controls, fullscreen, byline, title, portrait
- **Copy embed code** — one click to copy the iframe HTML

Open `index.html` in a browser. No build step.
