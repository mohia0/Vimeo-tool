# Vimeo Embed Tool

Minimal tool to customize Vimeo embed appearance. Paste a Vimeo URL or video ID, toggle options, and see the embed code update live.

- **Live preview** — changes reflect immediately
- **All main embed options** — badge, autoplay, loop, muted, controls, fullscreen, byline, title, portrait, pip, background mode, and more
- **Copy embed code** — one click to copy the iframe snippet

Open `index.html` in a browser. No build step.
